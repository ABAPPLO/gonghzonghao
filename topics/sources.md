# 信息源手册（AI 行业资讯号）

> 用途：选题步骤「先搜当日热点」的固定信源库。整理于 2026-09-22。
> 优先级原则：**官方一手 > 独家/深度媒体 > 聚合快讯 > 社区讨论**；榜单类产品迭代快，失效时以最新为准。
> 标记：⭐ = 核心必看；其余为备选/补充。

## 每日监控 SOP（约 20 分钟）

1. **厂商公众号**（⭐，5 分钟）：扫一遍置顶的 5～8 家厂商号，记下发布/更新公告
2. **快讯媒体**（⭐，5 分钟）：机器之心 / 量子位 当日推送 + X 上关注的官方号
3. **海外补充**（5 分钟）：Hacker News 首页 + Reuters/Bloomberg 科技版块
4. **判断**（5 分钟）：
   - 有大发布/大独家 → 插队做「深一度」，当天出稿
   - 有 3 条以上小动态 → 汇总成「AI 早报」
   - 榜单/报告更新 → 排进「榜单·数据」
   - 都没有 → 从 `backlog.md` 待写池里挑

## 工具建议

- **RSS 聚合**：用 Folo / Feedly / Inoreader 订阅上面标 ⭐ 的海外源，一屏扫完；国内公众号用微信置顶 + 「公众号合集」功能
- **X 列表**：建一个「AI 官方号」私有列表，20 个号以内，每天刷一次
- **微信搜一搜关键词**：「大模型 发布」「AI 政策」「算力」，看 24 小时内文章密度判断要不要跟
